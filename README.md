# Student Career Guidance System

A responsive student project that helps learners explore possible career paths using interests, favorite subjects, and strengths.

## Features
- Career questionnaire and student profile fields
- Rule-based suggestions for careers to explore
- Skill summaries and suggested next steps
- Responsive design for desktop and mobile
- No server required; answers are processed in the browser

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — career matching logic

## Run locally
Open `index.html` in a modern web browser.

## Publish using GitHub Pages
1. Create a public repository named `Student-Career-Guidance-System`.
2. Upload all four files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site.

Expected URL format: `https://YOUR-GITHUB-USERNAME.github.io/Student-Career-Guidance-System/`

## Important note
This is an educational prototype, not a professional psychometric test or a guarantee of career fit. Suggestions are basic rule-based ideas. Verify official course and admission requirements and consult teachers or career counselors before making important decisions.
